Данное приложение предназначено для игры в крестики-нолики между двумя игроками.

Для запуска необходимо перейти в папку tictactoe\tictactoe\bin\Debug и дважды 
нажать на файл tictactoe. 

После запуска откроется окно Windows Forms с игровым полем, состоящим из девяти кнопок. 
Каждая кнопка представляет собой отдельную клетку, в которой игрок может поставить свою метку. 
Рядом с надписью «Ход» отображается количество сделанных ходов. 
В нижней части окна расположена кнопка перезапуска, позволяющая начать игру заново. 
Игроки ходят по очереди: сначала игрок X, затем игрок O. 
Для выполнения хода необходимо выбрать свободную клетку и нажать на неё. 

Цель игры — первым собрать три одинаковые метки в одну горизонтальную, 
вертикальную или диагональную линию. Победителем становится тот, 
кто первым выполнит это условие.
