1) Данное приложение предназначено для игры в крестики-нолики между двумя игроками.
2) Для запуска необходимо перейти в папку tictactoe\tictactoe\bin\Debug и дважды 
нажать на файл tictactoe. 
3) После запуска откроется окно Windows Forms с игровым полем, состоящим из девяти кнопок. 
<img width="507" height="557" alt="image" src="https://github.com/user-attachments/assets/463ac7e1-1f6a-4d9c-af36-66acd388b09e" />

4) Каждая кнопка представляет собой отдельную клетку, в которой игрок может поставить свою метку. 

5) В нижней части окна расположена кнопка перезапуска, позволяющая начать игру заново. 
<img width="143" height="35" alt="image" src="https://github.com/user-attachments/assets/6811b0e1-becf-4e0e-b446-10d7df25cc70" />

6) Игроки ходят по очереди: сначала игрок X, затем игрок O. 
7) Для выполнения хода необходимо выбрать свободную клетку и нажать на неё. 
![Uploading image.png…]()

9) Цель игры — первым собрать три одинаковые метки в одну горизонтальную, 
вертикальную или диагональную линию. Победителем становится тот, 
кто первым выполнит это условие.
